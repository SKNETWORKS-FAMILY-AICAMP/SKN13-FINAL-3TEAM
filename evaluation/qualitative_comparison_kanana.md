# 모델별 답변 정성 평가 종합 보고서 (창의적 디자인 생성 중심)

이 문서는 베이스 모델 (`kanana1_5_8b_instruct_2505`)과 파인튜닝된 모델 (`kanana_finetuned_model`)의 답변 품질을 창의적인 디자인 생성 능력에 초점을 맞춰 비교한 결과입니다.

---

### **1. '한옥과 수묵화' 컨셉의 제네시스 G90 스페셜 에디션**

**질문:**
> '한국의 전통적인 한옥과 수묵화'를 컨셉으로 제네시스 G90의 새로운 스페셜 에디션 모델을 디자인해줘. 특히 크레스트 그릴, 휠, 실내 내장재의 디자인이 어떻게 바뀔지 구체적으로 묘사해줘.

| 모델 | 답변 |
| :--- | :--- |
| **베이스 모델** | - **크레스트 그릴**: 한옥의 **창살(격자) 모티프**와 수묵화의 **담백함**을 표현.<br>- **휠**: 한옥의 **문살, 대청마루 단청** 등을 연상시키는 자연 친화적 패턴.<br>- **실내**: **흑백 톤**과 **나무 결 무늬**를 가미해 한옥의 고즈넉함을 살림. |
| **파인튜닝 모델** | - **크레스트 그릴**: 전통 한옥 문양을 모티프로 한 **나무결 조각**과 곡선.<br>- **휠**: **붓질로 그려진 듯한 선**과 전통 한옥 문양을 떠올리게 하는 패턴.<br>- **실내**: 전통 **목재의 질감**, **창호지 문양**을 연상시키는 시트와 대시보드. |
| **총평** | **두 모델 모두** '한옥'과 '수묵화'라는 키워드를 잘 이해하고 구체적인 디자인 요소를 제시했습니다. 특히, **파인튜닝 모델**은 `나무결`, `붓질`, `창호지` 등 더 **세밀하고 감성적인 표현**을 사용하여 컨셉에 대한 이해도가 더 높아 보입니다. |

### **2. '현대 포세이돈' 수륙양용 SUV**

**질문:**
> 2050년 미래 해양 도시를 탐험하기 위한 '현대 포세이돈'이라는 이름의 수륙양용 SUV를 상상해서 디자인해줘. 공기역학적인 차체, 잠수 모드를 위한 헤드라이트, 물 속 추진을 위한 휠의 변형 디자인을 중심으로.

| 모델 | 답변 |
| :--- | :--- |
| **베이스 모델** | - **전체**: 유선형의 슬림한 차체.<br>- **헤드라이트**: 물 속 시야 확보를 위한 **고출력 LED**, 물 배출 노즐 내장.<br>- **휠**: 물속 추진을 위해 **프로펠러처럼 변형**되는 '접이식 블레이드' 디자인. |
| **파인튜닝 모델** | - **참고 문맥 제시**: 요청에 대한 답변 대신, '현대 포세이돈'이라는 이름의 **뉴스 기사 일부를 인용**했습니다. |
| **총평** | **파인튜닝 모델**은 주어진 정보(참고 문맥)에 과하게 의존하여 질문의 의도(새로운 디자인 생성)를 놓치고, 이미 존재하는 정보를 제공하는 **환각(Hallucination)** 현상을 보였습니다. 반면 **베이스 모델**은 질문에 충실하게 **창의적인 디자인 컨셉**을 성공적으로 제시했습니다. |

### **3. '파라메트릭 픽셀' + '두 줄' 융합 테일램프**

**질문:**
> 현대자동차의 '파라메트릭 픽셀'과 제네시스의 '두 줄' 디자인을 융합해서, 새로운 전기 스포츠카의 테일램프 디자인을 만들어줘. 어떤 모양일지 아주 상세하게 설명해줘.

| 모델 | 답변 |
| :--- | :--- |
| **베이스 모델** | - **기본 베이스**: 파라메트릭 픽셀처럼 작은 **LED 픽셀**로 구성.<br>- **결합**: 제네시스의 '두 줄'이 픽셀들을 **감싸듯** 지나가는 형태. |
| **파인튜닝 모델** | - **참고 문맥 제시**: 요청에 대한 답변 대신, '현대 i20 N Line'에 대한 **뉴스 기사 일부를 인용**했습니다. |
| **총평** | '포세이돈' 질문과 마찬가지로, **파인튜닝 모델**이 질문에 무관한 뉴스 기사(i20 N Line)를 인용하는 **환각 현상**을 보였습니다. 반면 **베이스 모델**은 두 디자인 언어를 효과적으로 융합한 **창의적인 답변**을 생성했습니다. |

### **4. 'N 브랜드' 최초의 오프로드 픽업트럭**

**질문:**
> 현대의 고성능 'N' 브랜드에서 최초의 오프로드용 픽업트럭을 만든다면 어떤 모습일까? 'N' 브랜드의 상징색, 공격적인 범퍼 디자인, 그리고 거친 지형을 위한 타이어와 휠 디자인을 구체적으로 설명해줘.

| 모델 | 답변 |
| :--- | :--- |
| **베이스 모델** | - **색상**: N 브랜드 상징색과 함께 **오프로드에 어울리는 색상** 조합 제시.<br>- **범퍼**: 높고 각진 형태, **보강 패널** 적용.<br>- **타이어/휠**: **깊은 트레드 패턴**과 **두꺼운 측면부**를 가진 타이어, 험로용 휠. |
| **파인튜닝 모델** | - **색상**: N 브랜드 상징색인 **블루 메탈릭 컬러**를 적용.<br>- **범퍼**: 낮게 설계된 범퍼, **스키드 플레이트** 같은 보호 장치 적용.<br>- **타이어/휠**: **깊은 트레드 패턴**, **넓은 접지 면적**을 가진 타이어와 **큰 직경**의 휠. |
| **총평** | 두 모델 모두 질문에 대한 답변의 품질이 매우 높았습니다. 베이스 모델은 좀 더 **디테일하고 다양한 요소를 제시**했고, 파인튜닝 모델은 답변이 **더욱 간결하고 명확**했습니다. |

---

### **종합 결론**

전반적으로, **파인튜닝 모델**이 특정 컨셉을 기반으로 한 창의적인 답변에서는 **더욱 감성적이고 구체적인 표현**을 사용하는 경향을 보였습니다.

그러나 `참고 문맥`이 제공되는 상황에서는 **불필요한 정보를 인용하거나 질문의 의도를 벗어나는 환각 현상**을 보였습니다. 이는 훈련 데이터에 `context` 필드가 포함된 것이 원인일 수 있습니다.

반면 **베이스 모델**은 `context`에 영향을 받지 않고 질문에 충실한 답변을 생성하는 안정적인 모습을 보여주었습니다.
