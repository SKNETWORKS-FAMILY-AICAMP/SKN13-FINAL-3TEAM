# FLUX 모델 파인튜닝 결과 보고서

## 1. 서론
본 보고서는 FLUX 모델을 활용하여 현대차 이미지 생성에 대한 파인튜닝 결과를 요약합니다. 특히, LoRA(Low-Rank Adaptation) 기법을 적용하여 모델의 성능 향상 여부를 정량적 및 정성적으로 평가했습니다.

## 2. 파인튜닝 상세
FLUX 모델은 `black-forest-labs/FLUX.1-Kontext-dev`를 사전 학습된 모델로 사용하였으며, `mingyu-oo/HD-car-img-caption` 데이터셋을 활용하여 파인튜닝을 진행했습니다.

**파인튜닝에 사용된 주요 파라미터:**
*   **사전 학습 모델:** `black-forest-labs/FLUX.1-Kontext-dev`
*   **데이터셋:** `mingyu-oo/HD-car-img-caption` (이미지 컬럼: `image`, 캡션 컬럼: `caption`)
*   **출력 디렉토리:** `./FLUX_HD_LoRA_adapter`
*   **해상도:** 1024x1024
*   **학습 배치 크기:** 4
*   **그라디언트 누적 스텝:** 4
*   **그라디언트 체크포인팅:** 활성화
*   **혼합 정밀도:** `bf16`
*   **옵티마이저:** `AdamW`
*   **학습률:** 5e-5
*   **LoRA 랭크 (rank):** 16
*   **LoRA 알파 (lora_alpha):** 32
*   **학습 에포크:** 6
*   **캐시 Latents:** 활성화
*   **8비트 Adam 사용:** 활성화
*   **리포트 대상:** `wandb`
*   **검증 프롬프트:** "Designed by Hyundai, 3/4 front view, midsize sedan, three-box, balanced proportions, low stance, short overhangs, sleek beltline, clean body surfacing, angular shoulder lines, prominent grille, narrow intakes, sculpted hood, flush door handles, 19-inch multi-spoke wheels, low-profile tires, tinted glass, chrome accents, red paint"
*   **검증 에포크:** 1
*   **시드:** 42
*   **체크포인팅 스텝:** 200
*   **허브에 푸시:** 활성화

## 3. 평가 방법론

### 3.1. 정량적 평가
정량적 평가는 CLIP 점수와 FID(Fréchet Inception Distance)를 통해 이루어졌습니다.
*   **CLIP 점수:** 생성된 이미지와 프롬프트 간의 유사성을 측정합니다. 점수가 높을수록 이미지와 텍스트 간의 일치도가 높음을 의미합니다.
*   **FID:** 생성된 이미지 분포와 실제 이미지 분포 간의 유사성을 측정합니다. 점수가 낮을수록 생성된 이미지가 실제 이미지와 더 유사함을 의미합니다.

### 3.2. 정성적 평가 (GPT 기반)
GPT 모델을 활용하여 생성된 이미지에 대한 정성적 평가를 수행했습니다. 평가 기준은 다음과 같습니다.
*   **프롬프트 충실도 (Prompt Faithfulness):** 생성된 이미지가 주어진 프롬프트의 세부 사항을 얼마나 잘 반영하는가.
*   **디자인 품질 (Design Quality):** 이미지의 전반적인 디자인 완성도 및 미학적 품질.
*   **브랜드 정체성 (Brand Identity):** 현대차의 디자인 언어 및 특징이 얼마나 잘 표현되었는가.
*   **이미지 품질 (Image Quality):** 이미지의 해상도, 선명도, 노이즈 없음 등 시각적 품질.

각 평가 항목에 대해 Base 모델과 LoRA 모델의 성능을 비교하고, 더 우수한 모델을 선정했습니다.

### 3.3. 테스트 환경
테스트는 `FLUX/FLUX_test.ipynb` 노트북을 통해 진행되었습니다.
*   **기본 모델:** `black-forest-labs/FLUX.1-Kontext-dev`
*   **LoRA 모델:** `mingyu-oo/FLUX_LoRA_adapter` (LoRA 스케일 0.5 적용)
*   **프롬프트:** `./Dataset/test` 디렉토리의 `.txt` 파일에서 프롬프트를 로드하여 사용했습니다.
*   **추가 프롬프트 (`prompt_2`) 및 네거티브 프롬프트 (`negative_prompt_2`):** 이미지 생성 시 특정 디자인 제약 조건 및 불필요한 요소를 제거하기 위해 상세한 프롬프트와 네거티브 프롬프트를 활용했습니다.
*   **생성 이미지 저장:** Base 모델과 LoRA 모델로 생성된 이미지는 각각 `./test/base_prompt_2_add` 및 `./test/LoRA_prompt_2_add` 디렉토리에 저장되었습니다.

## 4. 평가 결과

### 4.1. 정량적 평가 결과

**CLIP 점수:**
*   **Base 모델 평균:** 24.020770656928587
*   **LoRA 모델 평균:** 22.04441933685474

CLIP 점수에서는 Base 모델이 LoRA 모델보다 약간 더 높은 평균 점수를 기록했습니다. 이는 LoRA 모델이 프롬프트와의 일치도 측면에서 미세하게 낮은 성능을 보였음을 시사합니다.

**FID (Fréchet Inception Distance):**
*   **Base 모델 FID:** 66.35466003417969
*   **LoRA 모델 FID:** 52.42274475097656
*   **우수 모델:** LoRA

FID 점수에서는 LoRA 모델이 Base 모델보다 현저히 낮은 점수를 기록하여, LoRA 모델이 실제 이미지 분포에 더 가깝고 더 사실적인 이미지를 생성함을 나타냅니다. FID 점수가 낮을수록 성능이 우수합니다.

### 4.2. 정성적 평가 결과 (GPT 기반)

GPT 기반 정성적 평가 결과는 다음과 같습니다. (각 항목 5점 만점)

| 평가 항목           | Base 모델 평균 | LoRA 모델 평균 | 우수 모델 |
| :------------------ | :------------- | :------------- | :-------- |
| 프롬프트 충실도     | 3.28           | 3.82           | LoRA      |
| 디자인 품질         | 4.00           | 4.18           | LoRA      |
| 브랜드 정체성       | 4.18           | 4.27           | LoRA      |
| 이미지 품질         | 4.64           | 4.55           | Base      |

**주요 분석:**
*   **프롬프트 충실도:** LoRA 모델이 Base 모델보다 프롬프트의 세부 사항을 더 잘 반영하는 것으로 평가되었습니다.
*   **디자인 품질:** LoRA 모델이 Base 모델보다 전반적인 디자인 완성도 및 미학적 품질에서 약간 더 우수했습니다.
*   **브랜드 정체성:** LoRA 모델이 현대차의 디자인 언어 및 특징을 더 잘 표현하는 것으로 평가되었습니다.
*   **이미지 품질:** Base 모델이 LoRA 모델보다 이미지의 해상도, 선명도 등 시각적 품질에서 약간 더 우수했습니다.

**LoRA 스케일 조정:**
LoRA adapter의 스케일을 0.5와 0.25로 조정하여 테스트를 진행한 결과, **0.5 스케일이 가장 좋은 성능**을 보였습니다. 이는 LoRA 가중치를 적절히 적용하여 모델의 생성 능력을 최적화했음을 의미합니다.

## 5. 결론
FLUX 모델에 대한 파인튜닝 결과, LoRA 기법을 적용한 모델이 전반적으로 Base 모델보다 우수한 성능을 보였습니다. 특히, FID 점수에서 현저한 개선을 보였으며, GPT 기반 정성적 평가에서도 프롬프트 충실도, 디자인 품질, 브랜드 정체성 측면에서 LoRA 모델이 더 높은 평가를 받았습니다. 다만, CLIP 점수와 이미지 품질에서는 Base 모델이 약간 더 우수하거나 비슷한 성능을 보였습니다.

종합적으로 볼 때, LoRA 파인튜닝은 현대차 이미지 생성 모델의 사실성 및 프롬프트 반영 능력을 효과적으로 향상시켰으며, 특히 LoRA 스케일 0.5가 최적의 성능을 제공했습니다. 향후 연구에서는 이미지 품질 저하 없이 CLIP 점수를 개선할 수 있는 방안을 모색할 필요가 있습니다.
